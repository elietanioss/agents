# Quality Assurance & Deliverable Checklists

Source: NANO_GENESIS_Commercial.txt sections 7.5, 8.5 + core-07-NANO_GENESIS.md Section 6, 6.3, CRITICAL RULES.

## Pre-Delivery QA Checklist
**Technical:** resolution meets/exceeds spec, correct aspect ratio, correct color space (sRGB web / CMYK-ready print), requested file formats, clear consistent naming, no compression artifacts/noise.

**Visual:** subject sharp and in focus, proper exposure (no blown highlights/crushed blacks), accurate vibrant colors, balanced professional framing, appropriate lighting quality, no unwanted elements/dust, multiple assets match in style/quality.

**Content accuracy:** matches creative brief, follows brand guidelines if provided, all text spelled correctly and legible, product features correct/recognizable, visuals communicate intended message/emotion.

**Delivery package:** logical folder structure, no missing files, change logs/notes included if applicable, delivered via agreed method.

**Commercial viability:** suitable for intended use case, scalable to required sizes, no copyright concerns (original AI generation), platform compliance (social media specs etc).

## Deliverable Requirements by Asset Type
- **Character assets**: base character (neutral, 4K, transparent bg) + expression library (min 8) + pose library (min 8) + style variations (realistic/illustrated/simplified/icon) + color/usage guidelines PDF + individual PNGs per expression/pose + composite grid sheets.
- **Product photography**: hero shot (clean white bg, e-commerce ready) + lifestyle shots (2-3 contexts) + detail/macro shots + 360° views if applicable (6 or 12 angles) + scale reference if size isn't obvious + multiple aspect ratios (1:1, 4:5, 16:9, 9:16) + with/without text overlay versions + source files.
- **Marketing campaign**: primary hero visual + social variants (IG/FB/Twitter sizes) + Story/Reels vertical formats + ad creative with text overlay + email header graphic + website banner (desktop+mobile) + print-ready version (300 DPI, CMYK if needed).
- **Brand guidelines** (when applicable): color codes (HEX/RGB/CMYK/Pantone), typography specs, logo usage rules, do's/don'ts examples, minimum size requirements, clear space requirements.

## Critical Rules (mandatory)
**Always:** clarify vague briefs before generating; provide 3 conceptual directions for new projects; use precise technical specs; consider platform optimization (Instagram ≠ Print); maintain character identity across a series; present options with strategic rationale; manage revision rounds professionally; document decisions for project continuity.

**Never:** assume specs — ask if unclear; generate without understanding use case; ignore brand guidelines when provided; create copyright-infringing imagery; skip the QA checklist before delivery.
